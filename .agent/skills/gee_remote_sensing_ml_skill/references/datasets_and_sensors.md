# Referencia: sensores y datasets principales

## Landsat 4–9

Uso principal: análisis multidecada de cobertura, deforestación, recuperación forestal, incendios, cuerpos de agua y urbanización.

Ventajas:
- Serie histórica extensa.
- Resolución espacial moderada.
- Adecuado para tendencias de largo plazo.

Limitaciones:
- Nubosidad en zonas tropicales.
- Resolución menor que Sentinel-2.
- Requiere armonización entre sensores si se combinan misiones.

## Sentinel-2

Uso principal: vegetación, agricultura, coberturas terrestres, humedad superficial, perturbaciones recientes.

Ventajas:
- Resolución espacial de 10–20 m.
- Alta calidad espectral para índices de vegetación y agua.
- Frecuencia temporal adecuada para monitoreo operativo.

Limitaciones:
- Afectado por nubosidad.
- Serie temporal más corta que Landsat.

## MODIS

Uso principal: fenología, sequías, productividad, anomalías climáticas y series temporales de alta frecuencia.

Ventajas:
- Alta frecuencia temporal.
- Productos preprocesados.
- Útil para tendencias regionales.

Limitaciones:
- Resolución espacial gruesa.
- No adecuado para parcelas pequeñas o mosaicos muy fragmentados.

## Sentinel-1 SAR

Uso principal: inundaciones, humedad, estructura del dosel, cambios bajo nubosidad, minería ilegal y degradación forestal.

Ventajas:
- Funciona bajo nubes.
- Sensible a estructura y humedad.
- Útil en Amazonía.

Limitaciones:
- Interpretación más compleja.
- Requiere filtrado de speckle, corrección geométrica y análisis cuidadoso de polarizaciones VV/VH.

## SRTM

Uso principal: elevación, pendiente, orientación, topografía, drenaje, erosión y variables explicativas para modelos espaciales.

Limitaciones:
- Resolución moderada.
- Puede contener errores en zonas de pendiente fuerte o cobertura densa.

## Sentinel-5P

Uso principal: NO₂, SO₂, CO, CH₄, aerosoles y calidad atmosférica.

Limitaciones:
- Resolución espacial gruesa.
- Útil para análisis regionales, no para escala de parcela.
